# AXON R1 — futuristic car site

A single-page concept-car site with scroll-driven motion (GSAP + ScrollTrigger).

Open `index.html` in a browser — no build step.

- **Hero** — letters and car animate in; on scroll the car rolls forward and the title lifts away
- **Drive** — pinned section: the car launches, speedometer counts to 412 km/h, wheels spin with scroll
- **Tech** — horizontal-scroll feature cards
- **Specs** — animated counters
- **Build** — paint configurator that re-themes the whole site
- Respects `prefers-reduced-motion`
